# KeyboardTest.tech Documentation Image Assets

This directory contains official branding logos, visual banners, and screenshot assets for the KeyboardTest.tech documentation repository.

## Directory Structure

```
images/
├── logo.png           # KeyboardTest.tech primary brand mark / logo
├── banner.png         # High-resolution documentation header banner
└── screenshots/       # Visual UI screenshots of keyboard diagnostic modules
    ├── keyboard-test-matrix.png
    ├── ghosting-test-view.png
    ├── nkro-counter-view.png
    └── latency-timing-inspector.png
```

## Image Specifications & Guidelines

- **Primary Logo (`logo.png`):** Transparent PNG, minimum 512x512px.
- **Header Banner (`banner.png`):** 1200x630px OpenGraph standard header graphic.
- **Screenshots (`screenshots/`):** High-DPI PNG screen captures of the virtual matrix in Dark Mode.
