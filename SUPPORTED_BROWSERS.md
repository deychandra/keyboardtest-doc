## 2. Technical Web APIs Utilized

To achieve accurate key state, ghosting, and latency diagnostics, KeyboardTest.tech relies on standard Web APIs:

### W3C `KeyboardEvent` Interface
- **`event.code`:** Identifies the physical key code on the keyboard rather than the character produced by keypress (ensures accurate visual key mapping regardless of OS language settings like QWERTY, AZERTY, or Dvorak).
- **`event.key`:** Identifies the string value generated by the keypress.
- **`event.repeat`:** Detects OS auto-repeat signals to prevent false double-press chatter flags.
- **`event.location`:** Differentiates between Standard (`0`), Left (`1`), Right (`2`), and Numpad (`3`) keys.

### High-Resolution Time API (`performance.now()`)
- Measures key press duration and interval latency with microsecond sub-millisecond precision (`0.005ms`).
- Eliminates standard `Date.now()` jitter for accurate hardware polling rate analysis.

### Hardware Acceleration & Animation Frame API (`requestAnimationFrame`)
- Syncs matrix UI renders to monitor refresh rates (60Hz, 144Hz, 240Hz, 360Hz, 540Hz).
- Guarantees zero DOM render bottlenecking during rapid N-Key Rollover testing.

## 3. Recommended Browser Settings for Optimum Testing Accuracy

1. **Hardware Acceleration:** Ensure GPU Hardware Acceleration is enabled in your browser settings (`chrome://settings/system`).
2. **Disable Intercepting Extensions:** Certain third-party browser extensions (such as Vimium, Bitwarden, or custom key-binding extensions) may capture specific keystrokes (`F11`, `Escape`, `Tab`) before they reach the page DOM.
3. **Focus State:** Keep the KeyboardTest.tech browser window active and focused during testing.
